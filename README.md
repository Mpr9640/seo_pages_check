# o1JobAid Resume SEO Page — React test repository

This is a **standalone React 19 + Vite 8 + JSX** preview of the public resume builder page. It is designed for GitHub Pages at https://mpr9640.github.io/seo_pages/ and is deliberately marked `noindex`.

## Run locally
Requires Node.js 22.12+ (or a supported newer version).

```bash
npm install
npm run dev
npm run build
```

You may commit the `package-lock.json` generated by `npm install` for reproducible builds. The workflow uses `npm install` so the initial deployment works without a lockfile.

## Deploy
Push to the `main` branch of `mpr9640/seo_pages`, then in GitHub Settings → Pages → Build and deployment choose **GitHub Actions**. The workflow builds and publishes `dist/` automatically. No Node installation is needed on GitHub Pages itself; GitHub Actions installs dependencies at build time.

## Testing routes
- Main URL: https://mpr9640.github.io/seo_pages/
- The React route `/ai-resume-builder` also works through client navigation. **Directly opening or refreshing that nested URL may 404 on GitHub Pages**, which lacks SPA rewrites. Use the main URL for this test, or add a 404 fallback/prerendering if testing direct nested URLs.

## Hand-off to the main application
- `src/pages/ResumeBuilderPage.jsx` is the reusable JSX component.
- `src/pages/resume-builder.css` is temporary isolated CSS; replace with the team's Tailwind/design-system styles later.
- `src/App.jsx`, `src/main.jsx`, `vite.config.js`, and `.github/workflows/deploy.yml` are **test-only scaffolding**.
- Update the CTA `href="/agent"` and related service links to verified production routes when integrating. On this GitHub Pages test, these are placeholders and can navigate to non-existent routes.
- Production SEO should remove `noindex`, add a correct canonical, render public content for crawlers (prerender or SSR), and add the **production URL** to the production sitemap, not the GitHub test URL.
- FAQs and service copy remain inside the JSX component so the team can restyle them without rewriting the content.
